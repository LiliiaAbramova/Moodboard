# Product Scope

## Product Roadmap Overview

The product is planned to be developed through several MVP stages.

---

# MVP 1 — Guest Moodboard Creation (Current)

Goal:
Provide basic moodboard creation functionality without user registration.

Features:

- Guest access
- View Unsplash gallery
- Search images by keywords
- Upload custom images
- Create moodboard
- Edit moodboard
- Export moodboard as PNG
- Clear moodboard

---

# MVP 2 — Registered User Account

Goal:
Provide personalized user experience.

Features:

- Google authentication
- User account
- Personal moodboards
- Limited number of moodboards per month

Example:

- Up to 100 moodboards/month

---

# MVP 3 — Subscription and AI-assisted Features

Goal:
Introduce monetization and AI capabilities.

Features:

- Subscription plans
- Unlimited moodboard creation
- Trial AI image generations

---

# MVP 4 — Advanced Subscription Plans

Goal:
Provide flexible plans based on user needs.

Features:

- Different subscription levels
- Different AI generation limits

---

# MVP 5 — Image Editing Features

Goal:
Expand creative capabilities.

Features:

- Image filters
- Additional image editing tools


---

# Current Testing Scope

This QA portfolio focuses on MVP 1.

Only implemented features are included in testing:

- Guest user flow
- Unsplash image search
- Image upload
- Workspace management
- Moodboard export
