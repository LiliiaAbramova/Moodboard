# User Roles

## Guest User

Current MVP supports guest users.

Guest users can:

- View application landing page
- Access image gallery
- Search images from Unsplash
- Upload personal images
- Create moodboards
- Edit moodboards
- Export moodboards


## Registered User

Planned for future MVP.

Registered users will have:

- Personal account
- Saved moodboards
- Increased moodboard limits
- Access to AI-assisted features
