# Test Plan

## Project

Moodboard MVP 1


## Testing Objective

The goal of testing is to verify that users can successfully create and export moodboards using available MVP functionality.


## Scope

### In Scope

- Guest user experience
- Unsplash image search
- Image upload
- Workspace functionality
- Moodboard export


### Out of Scope

- User authentication
- AI image generation
- Subscription functionality
- Payment flow


## Testing Types

The following testing types will be performed:

- Functional testing
- UI testing
- Usability testing
- Negative testing
- Cross-browser testing


## Test Approach

Testing will be performed manually first.

Test scenarios will be created based on user flows and product requirements.

Automation opportunities will be identified after manual testing.


## Risks

Potential risks:

- Unsplash API dependency
- Search requests return errors 
- Image upload issues 
- API rate limits are exceeded 
- Image positioning/layout 
- Export functionality 
- Data persistence limitations
